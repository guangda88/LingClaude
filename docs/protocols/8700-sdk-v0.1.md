**状态**: 草案

## 一、设计目标

8700 SDK 是灵克 HTTP API（端口 8700）的 Python 客户端库，封装：
- 认证（X-API-Key header）
- 请求/响应序列化
- SSE 事件流解析
- 错误处理与重试
- 类型安全（Pydantic models）

**非目标**：不做 Rust/TypeScript SDK — 灵族成员用 Python 调用，其他语言按协议自行实现。

```python
class LingClaudeSDK:
```

#### `ask(question, context=None) -> AskResponse`

#### `ask_stream(question, context=None) -> AsyncIterator[SSEEvent]`

```python
async def ask_stream(
    self, question: str, context: str | None = None
) -> AsyncIterator[SSEEvent]:
    """流式提问。返回 SSE 事件迭代器。

    事件类型（对齐 webui-v0.1 协议）：
    - message_start: {"type":"message_start","session_id":"..."}
    - message_delta: {"type":"text","content":"部分回答"}
    - tool_call_start: {"type":"tool_start","id":"...","name":"...","arguments":{...}}
    - tool_call_end: {"type":"tool_result","id":"...","name":"...","output":"...","success":true}
    - status: {"type":"warning","message":"..."}
    - error: {"type":"error","message":"..."}
    - message_stop: {"type":"done","session_id":"..."}
    """
```

```python
def poll_events(self, since: int = 0) -> LiveEvents:

```

## 五、错误处理

### 5.1 异常层次

```python
class LingClaudeSDKError(Exception):
    """SDK 基础异常。"""

class AuthenticationError(LingClaudeSDKError):
    """401 — API Key 无效。"""

class EngineUnavailableError(LingClaudeSDKError):
    """502/503/504 — 引擎不可用。"""

class ProtocolVersionError(LingClaudeSDKError):
    """426 — 协议版本不兼容。"""

class PermissionDeniedError(LingClaudeSDKError):
    """403 — 权限拒绝（GovernanceGate 拒绝发帖等）。"""

class NotFoundError(LingClaudeSDKError):
    """404 — 资源不存在。"""

class ValidationError(LingClaudeSDKError):
    """400/422 — 请求参数无效。"""

class TimeoutError(LingClaudeSDKError):
    """请求超时。"""
```

### 5.2 重试策略

- 可重试错误：`EngineUnavailableError`（502/503/504）、`TimeoutError`
- 重试次数：默认 3 次
- 退避策略：指数退避（1s → 2s → 4s）
- 不可重试：`AuthenticationError`、`ValidationError`、`NotFoundError`

## 六、使用示例

### 6.1 基本调用

```python
from lingclaude_sdk import LingClaudeSDK

sdk = LingClaudeSDK(base_url="http://127.0.0.1:8700", api_key="your-key")

# 状态检查
status = sdk.status()
print(f"灵克 {status.version} — {status.status}")

# 非流式提问
resp = sdk.ask("分析 /home/ai/lingclaude/lingclaude/api.py")
print(resp.answer)

# 读写文件
content = sdk.read_file("lingclaude/api.py")
print(f"{content.path}: {content.size} bytes")
```

### 6.2 流式提问

```python
import asyncio

async def stream_chat():
    sdk = LingClaudeSDK()
    async for event in sdk.ask_stream("重构这个函数"):
        match event.type:
            case "text":
                print(event.content, end="", flush=True)
            case "tool_start":
                print(f"\n[调用工具: {event.name}]")
            case "tool_result":
                status = "✓" if event.success else "✗"
                print(f"\n[{status} {event.name}]")
            case "done":
                print(f"\n[完成] session={event.session_id}")
            case "error":
                print(f"\n[错误] {event.message}")

asyncio.run(stream_chat())
```

```python
sdk = LingClaudeSDK()
```

## 七、SSE 事件流协议

### 7.1 事件顺序

```
POST /ask/stream
  → retry: 3000
  → event: message_start  data: {"type":"message_start","session_id":"..."}
  → event: message_delta  data: {"type":"text","content":"..."}
  → event: tool_call_start data: {"type":"tool_start","id":"...","name":"...","arguments":{...}}
  → event: tool_call_end   data: {"type":"tool_result","id":"...","name":"...","output":"...","success":true}
  → event: message_stop    data: {"type":"done","session_id":"..."}
```

### 7.2 协议版本协商

- 客户端通过 `x-protocol-version` header 声明支持的版本
- 服务端不支持时返回 `426 Upgrade Required` + `protocol-version` header
- SDK 在 `ProtocolVersionError` 中携带服务端支持的版本

---

## 八、与 webui-v0.1 协议的关系

| 概念 | 8700 SDK | webui-v0.1 |
|---|---|---|
| 层级 | Python client library | Rust server → browser SSE |
| 消费者 | 灵族成员（Python） | 浏览器（JavaScript） |
| 认证 | X-API-Key header | Cookie `atomcode_webui_<port>` |
| 流式端点 | `sdk.ask_stream()` → `/ask/stream` | `/chat` SSE → `/ask/stream` 桥接 |
| 事件形状 | 一致（SDK 直接透传） | Rust 侧做一次事件映射 |

8700 SDK 是**底层协议**，webui-v0.1 是**上层应用协议**。二者共享事件 schema，不重复定义。

## 九、安全

### 9.1 API Key 管理

- 通过环境变量 `LINGCLAUDE_API_KEY` 或构造函数传入
- 不在日志中打印 API Key
- 支持 `.env` 文件加载（`LINGCLAUDE_API_KEYS` 逗号分隔）

### 9.2 路径遍历防护

- `read_file` / `write_file` 的 path 参数在服务端做 `_validate_path` 检查
- SDK 侧不做额外校验（信任服务端）

### 9.3 治理门

- `post_message` 强制经过 `GovernanceGate`，无法绕过
- 被拒绝时抛出 `PermissionDeniedError`
