## 定位总结

**lingclaude = 重构专用 Agent + 本地隐私优先 + 自演化回路**

| 优势 | 劣势 |
|------|------|
| ✅ 代码重构/架构治理最强（P0-P5 自证） | ❌ 无沙盒、无自动规划、无 IDE |
| ✅ 记忆体系最完善（灵忆 2T3A） | ❌ 通用编码任务弱于 CC/Codex |
| ✅ 模型无锁、Token 极省 | ❌ 非交互式批处理场景不成熟 |
| ✅ 回路可审计、可复现 | ❌ 生产级部署仍需补安全/运维 |

**适用场景**：代码库重构、架构治理、技术债清偿、私有化部署、合规要求高的团队  
**不适用场景**：从零写新项目、需要 IDE 集成、需要自主规划复杂任务、对沙盒有强合规要求
