## 两篇论文（2026-09，已由主人精读，要点如下；如你的环境可联网，可自行抓取原文验证）

### 论文 1：《The Last AI Built by Humans: Toward Genuine Recursive Self-Improvement》（arXiv:2609.11873，清华/上交/字节/上海AI Lab 等联合综述）
核心概念：
1. **HCI (Headroom-Closed Index)**：跨基准归一化的「未闭合提升空间」指数，用于量化模型距能力上限还有多少可改进余量——现有 LLM 在多数基准上 headroom 正在闭合，改进越来越贵。
2. **改进循环七要素解剖**：AI system / System state（跨轮保留并继承的状态）/ Experience（来自交互、指导后续修改的信息）/ Target（本轮直接修改对象）/ Improver（生成候选修改的机制）/ Strategy（决定搜索哪里的方法，本身可成为后续 Target）/ Verifier（评估候选并执行接受规则）。RSI 的判定关键=哪些决策由谁控制、每轮闭合在哪里、为下一轮保留什么。
3. **五级自主性路线图**：B0（任务内改进）→ L1（改进执行自主：数据/训练方法/平台/评估/部署优化/应用系统）→ L2（改进策略自主：prompt 搜索/agent-harness 搜索/模型-训练搜索）→ L3（未来学习经验自主：自适应任务生成、self-play、环境交互练习）→ L4（部署与环境适应自主：轨迹蒸馏、迭代修订 agent 系统、选择性保留与部署更新，在外部接受与治理规则下）→ L5（元改进：改进搜索程序本身、改进后继评估器、修订研究目标与策略）。
4. **三大挑战**：①安全继承 Safe inheritance（持久化变更可能携带错误；Gödel Agent 100 次试验中 14% 低于初始策略；需要迁移测试/版本历史/回滚机制）②自主性归因 Autonomy attribution（候选变好≠改进了发现候选的方法；DGM 进化 coding agent 20%→50% 但档案维护与父代选择规则仍是外部硬编码；必须区分哪些是自改进哪些是外置）③可靠验证 Reliable verification（反复访问评估器会奖励exploit：随机种子挑樱桃、尝试提取测试标签；评估器本身演化会破坏跨轮可比性）。
5. **第 6 章四大方向**：跨组件诊断与协同改进（一个失败无法定位该改哪个组件——数据/上下文/工具接口/模型；应把诊断转成可检验的干预假设+受控对比）、学习者条件化的经验获取与可靠学习信号（经验的合法性/难度/持久收益三属性）、持久状态管理与可靠复用（继承的 artifact 要关联证据、适用条件、依赖、对后续任务的观测效果；准入测试如 HDSO 配对评估）、领域特定反馈下的受治理适应。

### 论文 2：《What if automating AI R&D triggers an intelligence explosion?》（arXiv:2609.36054，Hinton/Bengio/Pachocki 等联署）
核心论证：
1. 现状证据：AI 已写出构建它的公司内的大部分代码（Anthropic 批准代码中 AI 占比从个位数百分比快速上升）；最佳系统完成 AI R&D 任务的时间视野从 2023 年的秒级 → 小时-天级（METR 时间视野约 3 个月翻倍）。
2. 软件驱动的智能爆炸存在连贯路径：R&D 自动化的生产力收益尚未达到触发阈值，但新系统正在逼近；r>1 时自动化劳动再投入 R&D 会自持加速。
3. 三大风险：能力增长超过社会驾驭速度、人类监督与控制丧失（人类失去参与机会与专业性）、权力制衡被侵蚀。
4. 三大政策支柱（映射到单个 agent 系统同样成立）：**Visibility 可见性**（对自动化 R&D 管线的观测与度量）→ **Steer & Constrain 导向与约束**（部署前提条件、能力增速限制、合规验证工具、可暂停特定工作负载、隔离环境）→ **Adapt 适应准备**。
