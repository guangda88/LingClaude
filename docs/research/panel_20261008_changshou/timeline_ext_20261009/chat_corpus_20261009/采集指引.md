## 二、语料用途与格式约定（重要）

**目标**: 口述史时间轴补源 + 访谈提纲素材（延续 M0 四层锚点：年代/人物/地点/班级期号）
**优先内容**（见到就采）:
1. 老功友**亲历回忆**（「我 199X 年在丰润/秦皇岛…」）
2. **期/班级号**提及（第五期、98级、教练员班…）
3. 讲课/话疗音频的**个人笔记**（如 99 年集训笔记 docx 那类）
4. 群里流传的**手抄/翻印文献**（拍照/文字均可）

**格式约定**: 文件名 = `群名或主题_时间段.txt`（如 `丰润功友群_2020-2026.txt`）
**每文件建议** ≥100 条消息为宜，多少都收

## 三、管线做什么（您丢文件就行）

1. **秘级红线**：路径含「注意保管的资料」直接拒收（延续 restricted_directories.conf 红线，独立生效）
2. **解析**：微信 PC 粘贴 / QQ 导出 / CSV(留痕工具等) / 通用兜底，四种形态
3. **脱敏**：手机/座机/邮箱/微信号/QQ → 本地哈希占位（salt 随机，不入库；同号跨批哈希不同属预期）
4. **质控标记**：外链/疑似广告/位置分享/占位消息（图片语音）——只标记不删除，决策留给人工
5. **台账**：`reports/接收台账_<批次>.md`（消息量/脱敏统计/质控统计）
6. **原始文件不动**：inbox 原样保留，parsed/ 为脱敏产物
