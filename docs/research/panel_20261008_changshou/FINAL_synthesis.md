## 〇、本终稿相对此前所有版本的四个根本修正（先读这个）

## 二、产品定义

### 2.1 双模式（法律地位不对等——ac 核心贡献，全票采纳）
| | 模式A「听他讲」= **产品本体** | 模式B「与智能人谈天」= **受限次级** |
|---|---|---|
| 性质 | 采集资产：录音→转写→记忆卡→时间线→成书 | 可溯源知识对话，**不绑定人格化角色**（规避"虚拟亲属/持续情感互动"定性风险） |
| 能力分档 | — | B1 问答（只读语料+出处，无匹配明说）/ B2 回听（只引用长者本人原话，标注日期）/ **B3 建议·健康·功法功效 = 不提供** |
| 互通 | 时间线缺口驱动谈天话题 | 谈天洞见落回时间线，生成"待补线索"，下次 A 模式开场即问（**互为燃料**，ac §6.4） |

lc 补充裁决（对 codex"谈天为留存引擎"与 ac"受限次级"的折中）：**B 保持一等入口但内容随 A 沉淀解锁**——冷启动无个人记忆时 B 只有 B1，规避"冷冰冰屏幕"留存陷阱。

### 2.2 目标用户（ac 三类主次）
长者 65+（主，被倾听/成果看得见）；家属（默认只读+逐项授权批注）；机构（B端：养老机构/老年大学/出版社）。

### 2.3 明确不做（合并 ac §12.4 禁止清单 + 各稿红线）
不做逝者声音/数字复活；不做"孙辈/亲属"人格自称；不回答"我这情况能不能练"；不打分不排名不徽章；不诱导"多讲一点"；不做老人付费订阅（30条罚则下战略决策，ac A9：家属付费+B端）；不收集未成年人信息；危机表述不继续对话（13条→安抚+紧急联系人）。

## 三、系统架构（ac 骨架全票 + codex 修订链）

```
[H5/Vue3+Vant4] 采集(MediaRecorder分片/大按钮/音量可视化) 播放(出处抽屉/批注视图) 无障碍(字号三档/单手区)
   │ WebSocket(会话态) + HTTPS(资源)
[FastAPI] BFF(鉴权/限流/断点续传) · 会话状态机(服务端,换设备不丢) · 异步作业(转写/抽取/嵌入/章节/导出)
[数据面] PostgreSQL+pgvector 单库(记忆卡/线索/版本/授权/审计 + 向量同事务) + 对象存储(加密音频,永不覆盖)
[外部能力统一抽象] ASR(方言云ASR→Whisper自托管) · TTS(本人音色受控) · LLM三通道(P/O/L,§五) · 语料本地Git仓(CI每日同步)
```
**五条架构决策**（ac §7.2，lc 确认采纳）：① PG+pgvector 单库——删除必须原子（16条）；② 音频本地优先+加密+当次确认；③ 状态机在服务端；④ 语料/记忆卡分开索引统一召回接口，结果带 `source_type`；⑤ **导出不是功能是管线**，第一天就与写入并行维护。

## 四、记忆与知识库

### 4.1 五层记忆（ac 修正版，替代 deepseek"进化记忆"）
L0 工作记忆（会话态）→ L1 情景（转写+音频）→ L2 语义（记忆卡,PG 可版本化）→ **L3 线索记忆（未解线索/矛盾/待核——"欠账"而非"进化"，ac 原创洞察）** → L4 谱系（语料只读）。

### 4.2 记忆卡 schema 定稿（豆包底 + codex + ac 扩展）
`memory_id/subject_id/session_id` + `timecode_start/end`（回听基石）+ `原文(逐字)/转写(可错)/摘要` 三分离 + `年代/地点/人物 各带{值,置信,依据}` + 情绪/主题标签 + `体裁: 记忆|待核|矛盾|拒入回忆录` + `版本{当前,历史[]}` + `授权{可入回忆录,可公开,授权人,时间}` 内嵌（16/18条义务落在数据本身）。codex 的 `sensitivity` 条目级分级、`timeline_bucket` 双轴并入。

### 4.3 "不纠正"与"可修正"双层机制（ac §9.5，裁决豆包版内部矛盾）
**采集层只复述不修改**：发现矛盾→不当场纠正，记"矛盾"存双值+证据，问句降级为"这两个年份我记着两个，您还记得是哪个吗"（请他定夺≠纠正）。**编辑层可修正**：本人/家属事后改，出新版本，旧版永久保留；正文永远附"本段由AI依据X月X日录音整理，请核对"。

### 4.4 语料工程（ac ✅实测 + lc 确认）
Gitea API 直接抓取（不依赖 IMA）：CI 每日 `clone --depth=1` 自持；清洗剥离`【】`校对标记**双份保存**（clean版召回展示/raw版引用出处）；**按章节切不按字数切**，每块带教材级别/体裁/路径/git_commit；bge-m3 类嵌入（⚠需实时核验）；BM25+向量+元数据过滤 RRF；回答必附`路径+章节+commit`。大事记时间轴：年-事件-人物三元组抽取→**人工校对**（对齐校对凡例）→兼作时代锚点题库（atomcode 增量保留）。

### 4.5 知识库选型终裁（ac §9.3 可核属性表 + kimi 精确化）
| | 角色 | 关键事实 |
|---|---|---|
| **PG+pgvector 自持** | **唯一主存** | 创建/删除/导出全✅，合规闭环 |
| IMA | 可选只读镜像/分发 | ac 纠正 kimi：知识库文件侧只增查 ✅；**笔记侧有写无删**（import_doc/append_doc/get_doc_content ✅ v1.1.2）——但"无删除"一条即否决其作主存（16条法定删除权） |
| 飞书多维表格 | 机构运营看板（不碰原始音频） | API 成熟 |
| Obsidian | 个人导出格式，非产品方案 | — |

### 4.6 召回策略（ac §9.6，修正豆包"固定3-5条"）
三路并行：① 结构化线索召回（L3 未解且时间接续）② 章节目标召回（本章必备要素清单）③ 向量模糊召回（辅，Top-K 动态 0-5）。注入卡必标"这是他上次讲的"+timecode；超 8 条按本章相关度裁剪，宁缺毋滥。

## 六、语音方案（本人音色克隆 = 最高规格授权）

### 6.1 ASR（最高技术风险，EchoVoices 结论）
方言云 ASR（⚠方言覆盖需实测）→ Whisper+k-NN 自托管降级；**术语热词表从语料自动抽取**（"捧气贯顶""形神庄"…对识别率提升预计大于换模型）；句级 timecode（低于句级则回听体验崩塌）；家属改字通道；**原始音频永不覆盖**。

### 6.2 TTS 四用途边界（ac §10.3 表，全票采纳）
AI 引导语=通用声；**复述原话=本人音色（克隆唯一正当用途之一）**；回忆录朗读=本人音色（招牌功能）；已故亲人声=绝对禁止。

### 6.3 克隆 8 步路径（ac §10.4，卡点制）
本人理解性同意（大字口述版确认书）→ **样本从已有访谈录音提取（不单独录制，降低负担）** → 质量门禁（不达标降级通用声，**不降级为"勉强克隆"**）→ 厂商必答"撤回后能否删除声纹？不能则弃用"（lc 前轮实测：自部署 GPT-SoVITS ✅官方README 5s零样本/1min微调，天然满足声纹删除；CosyVoice 备选）→ 显式+隐式双标识 → **运行时代码级校验：合成文本必须命中原话集合 timecode，越界拒绝（本方案最重要工程约束）** → 一键撤回立即退通用声 → 身故密钥层失效。

### 6.4 交互节奏（InTouch 证据，ac 核心补充）
响应延迟目标 **0.8-1.2s**（快被误读为抢话，慢被误读为没听见）；停顿 3-5s 主动说"您慢慢说"；**TTS 默认 0.85 倍速**（0.75/0.85/1.0 三档）。

## 八、H5 适老化（视觉+交互双层，ac §12）
视觉：正文≥18pt 三档持久化；按钮≥56pt；对比度≥7:1（高于 AA）；单手区=下1/3；每屏决策点≤1。
交互（qwen 版完全遗漏，ac 补）：**零倒计时零进度条压力**（25分钟管控=后端静默收束，前端只说"今天先聊到这儿"）；破坏性操作二次确认且"取消"更大；**永远有显眼"结束"出口**（19条，语音"不说了"也能结束）；**AI 身份常显**（18条）；方言是前置信息不是设置项（首页即问"您平时说哪的话"）；弱网先录后传+"已经帮您存好了"；家属远程看进度不能代答。
家属协同边界（§13.3）：默认只读；写权限逐项授权可收回；看不到"拒入回忆录"卡；不显示"子女正在看"监控感元素。
