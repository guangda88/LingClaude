# 《与长寿智能人谈天》H5 产品完整方案（Codex 版）

> 立场声明：本文以用户原始需求为唯一事实基础，对四份参考材料（deepseek/豆包/kimi/qwen）做**批判性仲裁**而非拼接。
> 凡外部事实（模型 ID、API 能力、法规条文、竞品数据、定价/额度）一律标注 **[未验证]**，不编造数字。

---

## 0. 执行摘要（一页读懂）

- **产品一句话**：面向长者的 H5「口述回忆录 + 有据可查的谈天」双模态应用，把一次访谈变成一本可带走、可传家的书。
- **核心判断（与四份材料的主要分歧）**：
  1. **双模式是必须的**，不是加分项。名字里就有"谈天"，且"谈天"是长者复访的唯一理由（kimi 版 HereAfter 关停教训 + qwen 版"单向记录"空窗判定共同支持）。
  2. **IMA 只做"读侧增强"与"只增的外部语料源"，不做主存**。理由：OpenAPI 据 kimi 版实测为**只增查、无比对式更新/删除/导出**（**[未验证]**，需以官方文档与实际 key 复核）；回忆录的更正/修订/导出权是产品生命线，不能寄存在不可回写的平台上。IMA 恰在"智能气功大事记"这类**公共只读语料**上发力。
  3. **主存自持**：Postgres（记忆卡原文 + 修订链）+ pgvector/milvus（向量）+ 对象存储（原始录音）+ 导出流水线，全部自有、可导出、可迁移。飞书/Obsidian 作为**可选镜像/工具面**，不作权威库。
  4. **音色克隆按"本人"定位，而非"复活亲人"**。禁止合成已故亲友声音（伦理红线，见 §11）。
- **时间轴定位**：智能气功大事记是**领域时间轴（domain timeline）**，不是"用户生平时间轴"。二者要在产品上显式分离，否则会把用户的 1962 年和行业的 1980 年代混为一谈（这是四份材料里最普遍的盲区）。

## 1. 业界同类项目调研（案例 / 实现逻辑 / 借鉴点）

> 以下案例的**规模数字、用户数、价格、融资**均为二手信息，标 **[未验证]**，仅用于判断赛道形态，不作论据。

| 项目 | 形态 | 实现逻辑（可观察部分） | 可借鉴 / 不可借鉴 |
|---|---|---|---|
| StoryCorps（美国） | 公益口述史 | 主持人对话 → 高质量音频 → 编辑整理 → 公共档案库 | 借鉴：**问题清单标准化**；不借鉴：英文语境、主持人必须是人 |
| 中文口述史项目（高校/地方志类） | 人工为主 | 提纲 + 采访 + 归档 | 借鉴：**主题提纲法**；不借鉴：人工成本不可规模 |
| HereAfter AI | 商业化 AI 回忆录 | 章节化问题库 + **只存真实录音、绝不合成** + 无匹配时礼貌婉拒 | 借鉴：**"不编造"是硬约束**；教训：**2026 年关停** [未验证] → 导出/接续计划/数据可携必须从 v0 设计 |
| 数字陪伴/数字人（国内多个"AI 奶奶/AI 爷爷"类 Demo 与小鹿光年类作品） | C 端小程序/H5 | LLM 对话 + 语音合成 + 简单排版 | 借鉴：适老 UI 与"陪伴话术"；警惕：**数据所有权伦理争议**（子女付费 vs 长者自主） |
| 已故亲人声音通话类（如"时空电话局"类） | 商业娱乐 | 声音克隆 + 对话模型 | **明确不借鉴**：情感操控与逝者人格权风险 |
| 智能气功/气功类史志语料库 | 公开文本仓 | 教材/专著/杂志/其他分类 + README/校对凡例 | 借鉴：**分级语料 + 校对凡例（可信度分层）** |

**共性实现逻辑（可归纳为 6 段链路）**：
引导访谈 → 录音采集与 ASR 转写 → 结构化记忆抽取 → 检索增强的跨会话记忆 → 回忆录组装 → 导出/展示。
四份材料在这一点上高度一致，**这是本方案唯一全盘接受的共识层**。

**四份材料的共同盲区（本方案重点修补）**：
- B1：都把"知识库"当 RAG 附件，忽略**"知识库 ≠ 记忆库"**：一个是公共只读语料，一个是用户私域且必须可修订可删除。混用会导致无法删除用户数据。
- B2：都未处理"**行业时间轴 vs 用户时间轴**"的错位风险。
- B3：都未把"**长期留存与项目存续**"（HereAfter 教训）提升为架构约束。
- B4：多数未明确 ASR 对方言/口音的**降级策略**（kimi 提"方言兼容"但无方案）。

## 2. 产品定义

### 2.1 目标用户
- 主用户：**60 岁以上**、有表达欲或被子女鼓励表达的长者（含方言使用者、低识字/低视力人群）。
- 次用户：子女/家属（代为设置、后期编辑、**但无默认读取权**）、志愿者/护理员（现场辅助）。
- 排除用户：未成年人（合规与伦理双重理由）。

### 2.2 两种模式（仲裁结论：**双模式，且以"谈天"为留存引擎**）
| | 模式 A「听他说」 | 模式 B「与智能人谈天」 |
|---|---|---|
| 主语 | 长者 | 系统中的"智能人"（智能气功领域引路人） |
| 输入 | 一次 15–25 分钟访谈 | 任意提问/闲聊 |
| 输出 | 结构化记忆卡 + 回忆录章节 | 可溯源回答 + 可选关联回用户自身记忆 |
| 知识依赖 | 弱（靠人） | 强（靠 IMA/本地公共语料 + **带出处**） |
| 失败代价 | 内容缺失 | **幻觉/编造**（最高风险） |

**仲裁理由**：产品名含"谈天"；只做 A 是"录音笔+"（豆包版实质方案），复访动机缺失；只做 B 则违背"口述回忆录"立项事实。双模式且 A 是 B 的**素材来源**，B 反哺 A 的追问线索——闭环成立。

### 2.3 核心用户旅程（Happy Path）
首次进入 → 语音授权 → 选择"聊今天"/"听你讲" → 3 分钟破冰（家乡/第一份工作）→ **20 分钟主访谈**（自动识别疲惫并收尾）→ 产出"今天留下了 3 段回忆"→ 可选试听本人音色朗读 → 邀请提问 → 每周一次"谈天"回访 → 满 3 个月触发《一辈子》成书。
**关键设计**：每次会话必须以**"我记住了什么"** 结尾（具象化收获），而不是以"是否要继续"结尾。

## 3. 系统架构

```
[H5 (移动优先, 微信内置 + 独立浏览器)]
  ├─ 采集层: MediaRecorder / Web Speech / 文件上传
  ├─ 呈现层: 大字幕流 / 单页卡片 / 语音回放
  └─ 弱网层: IndexedDB 暂存 + 断点续传 + 幂等上传
        │ HTTPS + 短时令牌
[API 网关 (FastAPI, 异步)]
  ├─ auth / consent / guardian 授权
  ├─ session 编排 (状态机, 单一权威)
  ├─ 记忆卡 CRUD (自持主库)
  ├─ RAG 编排 (BM25 + 向量 RRF 融合)
  ├─ 导出流水线 (PDF / 纸质打印稿 / 音频包)
  └─ 审计日志 (append-only)
        │
[Agent 编排层]  Interviewer / Scribe / Planner / Writer / Librarian(谈天) / Voice
        │
[LLM 网关]  统一模型抽象: 路由 / 降级 / 限流 / 成本闸门 / 提示词版本
        │
[数据面]
  ├─ Postgres: 记忆卡原文 + 修订链 (source of truth)
  ├─ 向量库: pgvector (首选) / milvus (规模化后)
  ├─ 对象存储: 原始音频 + 照片 + 导出物 (加密 + 保留期)
  ├─ 公共语料: 智能气功大事记 (自持镜像, 只读)
  └─ IMA: 只读检索 + 只增导入 (可选, 非权威)
```

**架构原则**
- P1 **单一权威**：Postgres 是唯一事实源；IMA/飞书/向量库全部可重建。
- P2 **可导出**：`export everything` 是一等公民接口（HereAfter 教训）。
- P3 **删除可验证**：删除用户数据后给出"已删除且无法找回"的凭据回执。
- P4 **提示词即资产**：所有 Agent 提示词版本化，可回滚，v0 就有。

## 4. Agent 拆分

| Agent | 职责 | 硬约束 | 失败回退 |
|---|---|---|---|
| **Interviewer 访谈师** | 单问题追问、情绪承接、线索追踪 | 一次只问一个问题；不纠正、不辩论；不说"你记错了" | 超过 2 轮无有效语音 → 切文字大字模式 |
| **Scribe 记录员** | 抽取记忆卡、标注来源（哪句原话、哪个时间点） | 必填 `verbatim`（原话），推断字段必须标 `inferred=true` | 抽取失败 → 存原文待人工/LLM 二次抽取 |
| **Planner 规划师** | 叙事空白检测、矛盾检测、下次追问清单 | 矛盾只"记录并追问"，不裁决真伪 | 低优先，可异步批处理 |
| **Librarian 谈天人** | 基于公共语料 + 用户自身记忆回答 | **无出处不回答**；命中不足时明确说"我手头资料里没有"；区分"这是你说的"vs"资料说的" | 检索空 → 引导切换到模式 A |
| **Writer 成书人** | 章节编排、保留原话、生成目录与草稿 | 零编造；所有叙述句可回指记忆卡 ID | 生成失败 → 模板化章节草稿 |
| **Voice 音色** | TTS 合成、断句、语速调节 | 无音色授权 → 用中性声；不合成第三方/逝者声 | 合成失败 → 静音 + 字幕 |

**不做的事**：不给长者做"情绪打分/心理评估"（易被误读为诊断，也带来合规负担）；不做"纠正事实"的智能体。

## 5. 记忆与知识库设计

### 5.1 记忆卡 Schema（采纳豆包版并扩展，取其可用部分）
```yaml
memory_id: uuid
session_id: uuid
speaker_role: subject | interviewer
spoken_at: ts
inferred_era: {label, confidence, basis}   # 依据线索推断年代，非断言
place: [str]
people: [{name, relation, alias}]
event_summary: str            # ≤ 80 字
verbatim: str                 # 原话，必填，允许长
emotion_tags: [str]
theme_tags: [str]
topic_domain: life | qigong_industry
timeline_bucket: {user_year, industry_year}   # 双轴，禁止混用
provenance: {audio_span: [start,end], asr_utterance_id}
inferred: bool
sensitivity: public | family | private
corrected_from: memory_id | null
version: int
status: active | retracted
```

### 5.2 分层记忆（对四版做合并仲裁）
- **工作记忆**：单会话上下文（短者 ≤ 2k token 摘要 + 结构化线索表）。
- **情节记忆**：会话级记忆卡列表（Postgres，含修订链）。
- **语义记忆**：向量化 + BM25 双索引，`RRF` 融合召回 top-k（k=5 上限 **[未验证] 为经验值**）。
- **领域知识**：智能气功大事记语料（只读，**带出处与校对等级**）。
- **进化记忆（可后置）**：记录"哪些问法让长者愿意多说"——这才是四版所谓"进化记忆"的真实价值，**不是**自我进化人格。

### 5.3 知识库三选（仲裁：**主存自持 + IMA 只读增强 + 可选镜像**）
| 维度 | IMA（据 kimi 版实测） | 飞书 | Obsidian | **本方案** |
|---|---|---|---|---|
| 写/改/删 | **只增查**（改删导无）[未验证] | API 成熟 [未验证] | 本地 MD | **Postgres 权威，导出自由** |
| 协作 | 强 | 强 | 弱 | 自建轻量：家属只读 + 提议修正 |
| 隐私 | 外部平台 | 外部平台 | 本地 | **数据默认不出境不出自持域** |
| 适合 | 公共只读语料检索 | 运营/人工审校 | 个人离线档案 | — |

**结论**：IMA 用于"智能气功大事记 + 混元灵通等公共语料"的检索增强与**只增**导入；**所有用户私域记忆留在自持库**。飞书可用于**内部运营/人工审校面板**（不作为用户数据仓）。Obsidian 作为**高级用户的可选导出格式**（zip + 向量库），不作为运行时主存。
> 隐私红线：私域内容**不得**在未获单独授权的情况下进入任何外部知识库。kimi 版"隐私分级通道"思路正确，补充一点——**授权粒度按条目，而非按会话**。

### 5.4 双时间轴模型（关键创新，四版均缺）
- `user_timeline`：用户人生事件，按推断年代 + 置信度排序。
- `industry_timeline`：智能气功发展大事记（来自语料源，含年份/事件/出处/校对等级）。
- **关联机制**：用户讲述涉及行业事件时（如"我在 1983 年教过气功班"），Librarian 补时代背景并**明确标注"这是资料补充，不是你说的"**；用户未确认前不写入 user_timeline 的行业关联字段。

## 6. 语音方案

### 6.1 ASR（输入）
- 主路径：云端通用 ASR（含方言/口音模型，具体厂商与能力 **[未验证]**）。
- 降级 1：浏览器原生 Web Speech（离线能力有限）。
- 降级 2：本地 Whisper 类模型自托管（CPU 可跑长音频，实时性一般）**[未验证性能数据]**。
- **强制约束**：
  1. 长者录音**优先保留原始音频**，ASR 仅作派生（kimi 版"绝不合成/真实音频"原则的正向应用）。
  2. 每条记忆卡必须回链 `audio_span`，可一键回听原声。
  3. 关键词纠错表（人名/地名/行业术语）由用户本人或家属确认后入库，用于热词增强。
  4. 低置信度片段进"待确认"队列，**不进入正文的确定性叙述**。

### 6.2 TTS（输出，本人音色克隆）——落地路径
1. **合规先行**：音色属于生物识别/人格要素，采集前需**单独授权页**（非打包在总协议里），可随时撤销并删除音色模型。
2. **采集规格（建议值，需实测校准）**：干净环境 5–10 分钟、覆盖情绪与语速的引导文本、≥ 若干段（具体条数**[未验证]**，不编造），允许中途放弃。
3. **训练路径**：优先选择**有明确授权条款、可私有化部署或明确数据留存政策**的商用声音克隆服务 **[具体厂商与商用授权条款 未验证]**；备选自托管开源克隆模型 **[未验证商业可用性]**。
4. **产品用法（受限）**：
   - ✅ 用于"我的故事"朗读、长者自己回听、回忆录有声版。
   - ❌ **禁止**合成逝者/亲友声音；❌ 禁止用于冒充长者对外发言；❌ 禁止用音色克隆生成长者未说过的话。
5. **标识**：所有合成音频带显式"AI 合成 · 本人音色"水印/元数据。
6. **降级**：无音色授权时用中性温暖声线，并说明"以后可以换成你的声音"（把音色当作**成长性奖励**而非准入门槛）。

## 7. 模型选型与路由

> **所有具体模型 ID、免费额度、上下文长度、限流数值均 [未验证]**，免费模型列表时效性以小时计，落地时必须实时核验并锁定到"能力探测结果"而非"文档承诺"。

### 7.1 选型原则
- P1 **能力探测优先**：上线前用固定测试集（长者口语、方言口音、追问质量、拒答纪律）实测 3–5 个候选，按实测分排序，不按宣传排序。
- P2 **降级链必备**：主模型不可用时自动降级，且**写作与抽取类任务降级后需人工/规则兜底**。
- P3 **零保留/不留存条款**：涉及私域语音与文本的调用，须确认供应商的数据留存政策 **[未验证，需逐家核对]**。
- P4 **出境评估**：若调用境外聚合平台（OpenRouter 类），按个人信息出境要求单独评估；评估未完成前**私域内容只走境内通道**。

### 7.2 路由表（角色 → 任务需求 → 候选池）
| 角色 | 任务特征 | 需求 | 候选 |
|---|---|---|---|
| Interviewer | 短输出、强规则遵循、低延迟 | 快、便宜、稳定 | Zen 快速档 / OpenRouter 免费档 [ID 未验证] |
| Scribe | 强 JSON schema、长上下文 | 结构化遵从 + 低幻觉 | 中等推理档 [ID 未验证] |
| Librarian | 检索 + 带出处拒答 | 知识锁定、长上下文 | 强推理档 + 检索 [ID 未验证] |
| Writer | 长文、文学性、可创作 | 长上下文、写作质感 | 强档 [ID 未验证] |
| 降级 | — | — | 极简档 + 规则化追问模板 |

### 7.3 会话守护（采纳豆包版并加强）
- 单会话 20–25 分钟硬上限（以长者疲劳为准，非以轮次为准）。
- 疲惫信号：重复、答非所问、长时间静默、语速下降 → **主动收尾**。
- 降级：语音→文字；文字→家属代录（需授权）；任何降级都记录并提示。
- 幂等：会话以 `session_id + utterance_seq` 幂等，防弱网重复写入。

## 8. H5 适老化设计

- 字号：正文 **≥ 18pt**（qwen 版给的 16pt 为下限，本方案取更保守值）；单一屏信息点 ≤ 1 个。
- 触控：主按钮 **≥ 56×56pt**（高于 44pt 下限），主操作位于屏幕下半部（单手可达）。
- 语音优先：进入即"按住说话"或"点一下开始说话"，不要求打字。
- 大字幕：实时字幕，字号大、对比度高（WCAG AA **[标准条款为已知事实，落地需逐页校验]**）。
- 零导航复杂度：**任何任务 ≤ 3 次点击**；首页只有两个大按钮（"聊今天" / "听你讲"）。
- 无陷阱：不设弹窗广告、不设倒计时消失、不设需要精细拖动的操作。
- 反馈：每次录音后给"听到了 40 秒"的即时确认，避免长者怀疑没录上。
- 无障碍：字体可调、朗读模式、高对比主题；**不依赖颜色单独表意**。
- 家属远程协助模式：家属可在自己手机上看到进度条（类似屏幕共享），但**不能代替长者应答**。

## 9. 数据、隐私与合规

- 采集：单独同意（音色）、单独同意（知情库/外部平台）、可撤回；遵循最小必要。
- 加密：传输 TLS、存储字段级加密、原始录音单独密钥。
- 权利：查阅、纠正、删除、可携（导出 zip）、撤回同意。
- **AI 生成内容标识**：回忆录成稿页眉固定"由 AI 辅助整理，故事由 XX 本人讲述"，录音原声可点播。
- 情感依赖：不做"只有我懂你"话术；设置使用频次提示与真人求助入口；不主动制造哀伤依赖。
- 未成年人：产品入口做年龄门槛声明；不收集未成年人信息。
- 法规条文（deepseek 版提到的"2026年7月15日《人工智能拟人化互动服务管理暂行办法》"等）：**[未验证]**，须以官方发布文本为准，并由法务在立项阶段出具适用性意见。**本方案不引用任何具体条文号与处罚数字。**
- 跨境：私域数据默认不出境；如使用境外模型，须完成出境评估并可关闭。

**对四版的批评清单**：
- deepseek 版：把"进化记忆"讲得过于拟人，未定义可度量行为；IMA 存储主张未考虑改删边界（与 kimi 版直接冲突，deepseek 版未标风险）。
