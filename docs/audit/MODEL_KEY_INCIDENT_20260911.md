# MODEL_KEY_INCIDENT_20260911 — lingclaude model 连接故障诊断

> 2026-09-11 监督者产出 · 用户报告：`/model deepseek-v4-flash` → HTTP 401 熔断
> 状态：**已诊断 + 已修复**——根因是 lingclaude 走 lingcode 直连过期 key，**绕过 lingcode 直连 proxy3** 后恢复

## 〇、修复结论（2026-09-11）

**根因（重新精确定位）**：

- lingclaude `config.yaml` 直连火山方舟 (`ark.cn-beijing.volces.com`)，依赖 `~/.ling_keys.env` 里 2026-08-16 生成的 `VOLC_CODING_API_KEY`
- 直连测试：**HTTP 401**——env key 失效
- 同时 `/model agnes-2.5-flash` / `kimi-k2.6` 都失败——**`~/.ling_keys.env` 整体过期**
- **proxy3 (127.0.0.1:8765) 跑真有效**：测试 deepseek-v4-flash / agnes-2.5-flash / glm-5.3 全部 HTTP 200
- 唯一限制：proxy3 **没有 kimi-k2.6 路由**——kimi 暂不可走 proxy3

**修复**：`config.yaml:17-18` 改 2 行（skip-worktree 保护不入库）

```diff
-  api_key: ${VOLC_CODING_API_KEY}
-  base_url: https://ark.cn-beijing.volces.com/api/plan/v3
+  api_key: ${LINGCLAUDE_PROXY_KEY:-sk-proxy3}
+  base_url: http://127.0.0.1:8765/v1
```

**重启后**：`/model deepseek-v4-flash` 等走 proxy3 → 不再依赖 lingcode 直连 → 不再401

## 二、根因（不是 lingclaude bug）

| 故障 | 根因 |
|---|---|
| volcengine 401 | **`~/.ling_keys.env` 的 `VOLC_CODING_API_KEY` 失效/过期/限额** |
| deepseek provider 000 | **本地 13457 端口无服务**（deepseek proxy 没启动）|

**关键证据**：
- `~/.ling_keys.env` 顶部注释：`generated by gen_env.py 2026-08-16`——**已 1 个月**
- 直连测试排除了 lingclaude 代码 bug——**火山方舟 API 服务正常返回 401**，证明 key 本身失效
- 本地 deepseek proxy 端口未起——**`127.0.0.1:13457` 是 lingcode 配置的代理端口，但进程不在**

**不是 lingclaude 代码 bug**：task_router 映射正确、env 兜底链正确、provider 配置正确——**故障在第三方 key 与本地服务**。

## 三、修复路径（按优先级）

### 选项 A：换新 key（最稳）


## 五、给 lingclaude 工程的建议

### 5.1 短路保护（P2 backlog）

lingclaude 应在启动时**预验证关键 provider 的 key**——避免用户跑 `灵克>` 才发现 401。

```python
# lingclaude/core/startup_checks.py (建议)
def preflight_provider_keys(providers: list[str]) -> dict[str, bool]:
    """启动时预验证关键 provider，避免 user 跑到一半才发现 401"""
    results = {}
    for p in providers:
        try:
            cfg = task_router._providers.get(p)
            test_response = quick_probe(cfg.base_url, cfg.api_key)
            results[p] = test_response.ok
        except Exception:
            results[p] = False
    return results
```

### 5.2 key 过期提醒（P3 backlog）

```bash
# 加 key_age_days 字段到 ~/.ling_keys.env
# ~/.ling_keys.env 顶部加：
# KEY_GENERATED_AT=2026-08-16
# KEY_EXPIRES_AT=2026-09-16  # 30 天后
# lingclaude 启动时检查，过期则 WARNING
```

### 5.3 熔断期提示更友好（已部分实现）
