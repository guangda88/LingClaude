## 四、关键决策与技术教训

1. **数据源定性**：「讲课时间」文件实为**多媒体资产索引**（`时间_地点_主题.ext`）——M0 ASR 支线的现成清单，地点 TOP：北京海淀大学179/石家庄65
2. **双线拆分**：大事记体（机构事件）vs 第一人称回忆体（个人经历）不混表；班级不与事件连边（证据源不同：m1 句库 vs v4 事件集）
3. **链接率 53% = 诚实值**：首跑 67% 含假边（“在石家庄/受到”类粘连误标键），三轮质量闸（键级停用+前缀过滤+省市归并+污染正名剔除）后回落
4. **归并正名=簇内最高频成员**（非最短形）：`华夏智能气功培训中心`(160) 胜出
5. **期号在班名前是主形态**（59:19）；师资班按「级」；杂志期号（详见本刊1997年第6期）必须排除
6. **原 CSV 是 GB18030+多行引号字段**：必须 `bytes→decode('gb18030')→csv.reader`，行级解析会拆散跨行字段
7. **bash 陷阱**：输出溢出→落盘 `data/spill/`；`cut -c`/`head -c` 多字节截断产生非法字节（3 次踩坑）；dict-repr 文本用 `split('\\n')` 非 splitlines
8. **冲突不静默改**：《气功探邃》1985 内部版 vs v4 的 1981/1983/1988 双源保留；「1996年5日」缺月保留不瞎补；所有冲突入 m0d_并入报告.md
