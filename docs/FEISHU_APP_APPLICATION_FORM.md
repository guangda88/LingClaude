# 飞书自建应用开通申请单（给主人，约 30 分钟）

> 用途：打通 lc 全自动飞书链路（读文档 / 写文档 / docx 导入 / 知识库检索 / 发消息）。
> 申请完成后，lc 将获得「官方 API 身份」，替代此前 8 条被防御性拦截的浏览器自动化路径。
> 依据：官方 MCP 0.5.1 README 明确其不支持直接编辑云文档；自建应用 + OpenAPI 是官方支持的正道。

## 一、开通步骤（6 步）

| # | 动作 | 要点 |
|---|---|---|
| 1 | 打开 open.feishu.cn → 开发者后台 → 「创建企业自建应用」 | 名称建议：`灵克飞书助手`；描述：`灵克(LingClaude)个人助理：文档读写、教程导入、知识库检索` |
| 2 | 应用详情 → 「添加应用能力」→ 开启 **机器人** | im:message 发送权限依赖机器人能力；不开启则申请了权限也用不了 |
| 3 | 「权限管理」逐条开通（见下表） | 搜索关键词找到对应权限后点开通；精确权限串以页面为准 |
| 4 | 「安全设置」暂不配置重定向 URL | v1 不做 OAuth 用户授权，只用 tenant_access_token（应用身份） |
| 5 | 「应用发布」→ 版本创建 → 提交发布 | 可用范围选「**仅自己**」；企业自建应用一般需管理员（或你自己）审核通过 |
| 6 | 「凭证与基础信息」页复制 **App ID / App Secret** | 交付方式见第三节 |

## 二、需要的权限（按功能需求，5 项）

| 功能 | UI 搜索关键词 | 用途 |
|---|---|---|
| 读写云文档 | `docx` / `文档` | 重写两篇说明书、日常文档维护（修复"标题里塞正文"问题的根治手段） |
| 上传/导入文件 | `drive` / `导入` | docx 教程导入（Q2 图文并茂版的自动上传） |
| 读写知识库 | `wiki` / `知识库` | 检索/挂载 wiki 节点（两篇文档都在 wiki 空间） |
| 发送消息 | `im` / `消息` | 作业提交回执、任务完成通知（发给你本人） |
| 读取文档元信息 | `文档` / `基本信息` | 导入任务轮询、文档链接解析 |

⚠ 诚实标注：精确权限串（如 `docx:document`、`wiki:wiki:readonly` 等）本轮未能在线核实（搜索引擎无返回、文档站为 SPA 壳），上表给的是**功能需求 + 搜索关键词**，请在权限管理页搜索框里按关键词勾选；lc 首次冒烟测试时会逐项验证，缺哪个回执里列出来再补。

## 三、凭证交付（安全约定）

1. 在本机新建文件：`~/.config/lingclaude/feishu_app.json`，内容：
   ```json
   { "app_id": "cli_xxxxxxxx", "app_secret": "在这里粘 Secret" }
   ```
2. 执行：`chmod 600 ~/.config/lingclaude/feishu_app.json`
3. **三条铁律**（lc 已自缚）：不进 git（已确认 yitang/.gitignore 机制可加排除）；不进 skills 目录（cc 评审强调的安全红线）；不写进任何日志/回执明文（回执只出现 App ID）。

## 四、lc 收到凭证后的自动验收（无需你参与）

| 冒烟项 | 通过标准 |
|---|---|
| 取 tenant_access_token | HTTP 200 且 code=0（端点 `open-apis/auth/v3/tenant_access_token/internal`，页名强对应；**首调未验证**，失败则按官方页纠正） |
| 读一篇你指定的文档 | 能取到标题与纯文本 |
| 导入本机 `~/yitang/七维读书法AI教程.docx` | 产出新文档 URL，真标题/真表格/5 图原位 |
| 给你发一条测试消息 | 你收到「灵克链路已通」回执 |

## 五、回执模板（你填完贴给我）

```
App ID: cli_xxxxxxxx
凭证文件: 已放 ~/.config/lingclaude/feishu_app.json (600)
应用状态: 已发布/审核中
```

---

## 附：申请时的两个坑（提前避开）

1. **机器人能力必须在申请权限之前开**——顺序反了权限页可能搜不到 im 类权限。
2. **版本发布是独立动作**——只建应用不发版，API 会报 `app not released`（99991672 类错误）；企业自建应用发布通常即时生效或你本人（管理员）一键通过。
