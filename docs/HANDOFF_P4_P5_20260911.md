## 二、本会话环境异常记录（下次必读）

1. **git 写对象失败**：沙箱 `/dev/urandom` openat EACCES → `git add`/`commit` 全挂。
   解法：python 手工构造 loose object（zlib）+ `git update-index --cacheinfo` + 手工 tree/commit + `git update-ref`。
   ⚠️ 期间产生过 2 个脏提交（1621901/7d60d01 带引号垃圾路径），已重建线性历史指向 `4900365`，它们现悬空无害。
   注意 `git ls-files` 必须加 `-z`，否则 C-quoted 路径会被当字面文件名写进 tree。
2. **OOM**：内存 32G 但并发测试触发 OOM-kill（exit=137）。**测试必须分小批跑**（≤80 用例/批）。
3. ~~Rust 工具链不可用~~ **已破（2026-09-11）**：rustc 可用，仅默认 lld 链接器吃虚拟内存超 512MB 硬限；`.cargo/config.toml` 已固化 `-fuse-ld=bfd`，cargo 全流程恢复。
